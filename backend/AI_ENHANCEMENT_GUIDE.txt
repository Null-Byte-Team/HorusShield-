=====================================
CONFIGURATION - HOW TO CUSTOMIZE
=====================================

Location: backend/ai/ai_config.py

Key Configuration Options:

1. PERSONALITY
   config.set("personality.tone", "friendly")  # or: professional_helpful, technical, casual
   config.set("personality.emoji", "🤖")

2. CONVERSATION BEHAVIOR
   config.set("conversation.enable_memory", True)  # Remember past messages
   config.set("conversation.max_history", 20)      # How many messages to remember

3. AI MODEL
   config.set("ai_model.type", "hybrid")        # security_only, general_only, or hybrid
   config.set("ai_model.temperature", 0.7)      # 0-1: higher = more creative
   config.set("ai_model.reasoning_depth", "deep")  # shallow, medium, deep

4. SECURITY RESPONSES
   config.set("security.threat_level_display", True)
   config.set("security.auto_explanations", True)  # Explain what threats mean

5. GENERAL CONVERSATION
   config.set("general_conversation.enable_jokes", True)
   config.set("general_conversation.enable_small_talk", True)

6. LANGUAGES
   config.set("languages.default", "en")
   config.set("languages.supported", ["en", "ar"])

TROUBLESHOOTING
=====================================

Q: Horus not responding to general topics?
A: Check config.get("ai_model.type") - should be "hybrid" not "security_only"

Q: Language responses not working?
A: Ensure language parameter is "en" or "ar"
   Horus may fall back to English if there are config issues

Q: Want to remember conversations longer?
A: Increase config.set("conversation.max_history", 50)

Q: Want different personality?
A: Try different tones:
   - "professional_helpful": Default, informative
   - "friendly": Casual, warm responses
   - "technical": Detailed, technical explanations
   - "casual": Very informal, fun
