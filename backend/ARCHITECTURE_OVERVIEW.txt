CLASS HIERARCHY
===============

HorusAssistant (Main Interface)
  │
  ├─→ AdvancedHorusAssistant (Core Engine)
  │   ├─→ ConversationMemory (Tracks Conversations)
  │   │   ├─→ memory[] (Message History)
  │   │   └─→ metadata (Topic, Emotion)
  │   │
  │   └─→ Response Generators
  │       ├─→ Security Responses (Real Data)
  │       └─→ General Responses (Conversational)
  │
  └─→ AIConfig (Configuration)
      ├─→ Personality Settings
      ├─→ AI Model Parameters
      ├─→ Conversation Behavior
      └─→ Security Options


DATA FLOW - ASK HORUS
====================

1. CLIENT SENDS:
   {
     "query": "What's my security score?",
     "language": "en",
     "user_id": "user123"
   }

2. ROUTE HANDLER:
   - Extracts data
   - Validates inputs
   - Passes to HorusAssistant

3. HORUSASSISTANT:
   - Calls engine.ask()

4. ADVANCED HORUS ASSISTANT:
   - Gets/creates ConversationMemory for user_id
   - Adds user message to memory
   - Detects topic (security/general)
   - Retrieves security data from DB
   - Generates appropriate response
   - Adds response to memory
   - Returns response

5. API RETURNS:
   {
     "status": "success",
     "response": "🔍 Current Analysis: ...",
     "user_id": "user123",
     "language": "en"
   }

TOPIC DETECTION LOGIC
=====================

User Query → Extract Keywords → Classify Topic

Security Keywords:
├─ attack, threat, hack
├─ device, network
├─ port, scan, ddos
├─ lockdown, anomaly
└─ alert, breach, ...

General Topics:
├─ Greetings (hello, hi, مرحبا, ...)
├─ Jokes/Fun
├─ Small Talk
├─ General Questions
└─ Thank You, Praise, etc.

Result: "security" or "general"

├─ English (en)

Language Parameter:
