NEW API ENDPOINTS:
═══════════════════════════════════════════════════════════════════

1️⃣  POST /api/horus/ask
    Ask Horus any question
    Parameters: query, language (en/ar), user_id
    Returns: response, status, user_id, language

2️⃣  GET /api/horus/history/<user_id>
    Get conversation history for a user
    Returns: conversation_history[], message_count

3️⃣  DELETE /api/horus/history/<user_id>
    Clear conversation history
    Returns: status, message

4️⃣  GET /api/horus/config
    Get current AI configuration
    Returns: full configuration object

5️⃣  GET /api/horus/health
    Check if Horus is healthy
    Returns: status, service, version, capabilities
